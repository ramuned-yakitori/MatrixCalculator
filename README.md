# Matrix Calculate

C#の練習で作成した行列の計算プログラムです。

## 概要

行列に行基本変形を適用し、簡約階段行列（Reduced Row Echelon Form）を求めます。

## 使用言語

- C#

## 実行方法

1. Visual Studio 等でプロジェクトを開きます。
2. プログラムを実行します。
3. 行数m と列数n を半角スペースを開けて入力します。
4. 行列の要素を入力します。（各要素は半角スペースで分け、行は改行によって分ける）
5. REEF と入力する。

## 入力例
```
m×n行列
-------
m n
↓ ↓
3 5
----------
0 1 2 2 4
2 2 0 4 4
1 2 8 2 1
----------
指定のコードを入力  
・簡約階段行列化: REEF  
REEF  
```
## 現在の機能

- 行の交換
- ピボットの正規化
- ピボット列の消去
- 簡約階段行列への変換
